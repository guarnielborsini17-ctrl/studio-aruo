# GitHub Pages Note

GitHub Pages can only host a static frontend. The current Studio Aruo demo requires serverless API routes, Neon Postgres, and Vercel Blob uploads, so GitHub Pages is no longer the recommended target for this branch.

Use `docs/deployment.md` for the Vercel demo deployment.

If you only need a historical static showcase, deploy an older static-only branch. The current role login, artist rankings, collaborations, reviews, balance top-ups, and image uploads will not work on GitHub Pages.
