# 绘图员接单状态设计

## 目标

让每个绘图员在自己的工作台维护接单状态，并在该绘图员登录后的首页顶部显示。状态数据保存到 Neon，确保重新登录、换设备以及部署到 Vercel 后仍然一致。

## 范围

本功能包含：

- 绘图员工作台新增“接单状态”区域。
- 绘图员可以选择“繁忙”或“空闲可接单”。
- 绘图员可以填写最早可排期日期。
- 状态保存到当前登录用户的资料记录。
- 首页仅在绘图员已登录时显示当前账号的状态条。
- 未登录时隐藏整个状态条。

本功能不包含：

- 向未登录访客展示某位指定绘图员的状态。
- 在绘图员公开详情页展示状态。
- 保存状态变更历史。
- 排期日历、预约名额或自动冲突检测。

## 数据模型

在 `users` 表增加两个字段：

- `is_busy BOOLEAN NOT NULL DEFAULT true`
- `available_date DATE NOT NULL DEFAULT CURRENT_DATE`

`available_date` 对繁忙和空闲状态都保留，用于表达最早可以开始新项目的日期。现有用户迁移后默认处于繁忙状态，最早排期日期为迁移当天；绘图员之后可以在工作台修改。

用户 API 映射增加：

- `isBusy: boolean`
- `availableDate: string`

日期以 `YYYY-MM-DD` 字符串传递，避免前端时区转换导致日期偏移。

## 接口与数据流

沿用现有个人资料更新接口 `PUT /api/profile`，将其调整为部分更新接口，并增加可选输入：

- `isBusy`
- `availableDate`

接口只允许当前登录用户更新自己的状态。服务端验证：

- `isBusy` 必须为布尔值。
- `availableDate` 必须是有效的 `YYYY-MM-DD` 日期。
- 当前用户必须是绘图员。

请求未提供的资料字段保持原值，状态的独立保存不会覆盖头像、简介、价格备注或其他资料。成功后接口返回更新后的完整用户对象。前端使用返回值更新认证会话中的用户资料：首页状态条因此立即同步，不需要刷新页面。

## 工作台界面

在绘图员工作台的“展示资料”区域下方增加独立的“接单状态”面板：

- 使用二段式选择控件切换“繁忙”和“空闲可接单”。
- 使用日期输入框填写“最早可排期日期”。
- 使用“保存接单状态”按钮单独提交。

该面板与展示资料、套餐价格分别保存，避免修改状态时意外覆盖其他尚未提交的表单内容。移动端将状态选择和日期输入改为上下排列。

## 首页显示

首页导航状态条不再读取 `localStorage` 中的 `aruo_status`：

- 当前会话存在且用户角色是绘图员时，显示当前用户的 `isBusy` 和 `availableDate`。
- 未登录或用户不是绘图员时，不渲染状态条。
- “繁忙”沿用橙色指示点和“繁忙状态 / Busy”。
- “空闲可接单”沿用绿色指示点和“空闲可接单 / Available”。

移除旧状态的本地持久化依赖，防止数据库状态和浏览器状态互相冲突。其他仍在使用的本地数据上下文不受影响。

## 错误处理

- 日期为空或格式无效时，前端阻止提交并给出明确提示。
- 接口失败时保留当前表单输入，并显示“接单状态保存失败”。
- 保存期间禁用按钮，防止重复提交。
- 成功后显示“接单状态已保存”，并立即更新首页可见状态。

## 测试与验收

自动化测试覆盖：

- 用户映射正确返回 `isBusy` 和 `availableDate`。
- 个人资料接口正确保存状态，拒绝无效日期和非绘图员更新。
- 工作台包含状态切换、日期输入和独立保存逻辑。
- 首页登录绘图员时显示其状态，未登录时隐藏状态条。
- 旧 `aruo_status` 不再决定首页显示。

人工验收：

1. 登录绘图员账号，在工作台改为空闲并选择日期。
2. 保存后返回首页，确认状态和日期立即变化。
3. 刷新页面并重新登录，确认状态保持不变。
4. 退出登录，确认首页状态条隐藏。
5. 在桌面和移动视口确认控件与状态条没有重叠。
