# 绘图员单端第一版设计

## 目标

第一版仅开放绘图员注册、登录、资料维护、套餐价格和作品上传。设计师、排行榜、合作和评价功能暂时从前台关闭。

## 前台行为

- 新注册账号固定为绘图员，不再显示身份选择。
- 已有绘图员登录后进入绘图员工作台。
- 已有设计师登录后进入“功能还待开放”页面。
- `/artists`、`/artists/:id` 和 `/dashboard/designer` 显示“功能还待开放”。
- 顶部导航隐藏绘图员排行榜。
- 服务手册只介绍绘图员账号、资料套餐和作品上传。
- 绘图员工作台隐藏合作记录。
- 价格页不再提供查看绘图员套餐入口。

## 保留范围

- 设计师、排行榜、合作和评价的 React 页面源文件保留。
- 相关 API、数据库表和历史数据保留。
- 后续恢复时重新接回路由和入口即可。

## 验证

- 注册请求始终提交 `artist` 角色。
- 设计师账号登录后看到“功能还待开放”。
- 排行榜与设计师工作台旧地址无法进入原功能页。
- 绘图员工作台不显示合作记录。
- 类型检查和生产构建通过。
