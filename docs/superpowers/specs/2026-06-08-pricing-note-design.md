# 价格说明自定义设计

## 目标

绘图员可以在工作台填写一段统一的价格说明，价格参考页顶部提示框显示这段内容，不再显示当前两行固定文案。

## 交互

- 工作台“套餐价格”区域增加“价格说明”多行输入框。
- “保存套餐价格”同时保存套餐和价格说明。
- 价格参考页顶部提示框显示已保存内容，并保留换行。
- 内容为空时显示“可在绘图员工作台填写价格说明。”

## 数据

- `users` 表增加 `pricing_note` 文本字段，默认空字符串。
- 用户资料 API 负责返回和更新 `pricingNote`。
- 不复用个人简介 `bio`，避免两个用途互相覆盖。

## 验证

- 工作台保存后，重新加载仍能看到价格说明。
- 价格参考页显示自定义内容。
- 清空说明并保存后，价格参考页显示默认提示。
- 类型检查和生产构建通过。
