# 批量作品上传设计

## 目标

绘图员可以在工作台一次选择多张图片，并通过一次操作将它们依次上传。上传完成的作品立即加入工作台列表，并可由首页作品库读取。

## 交互

- “选择图片”文件输入支持多选。
- 选择后显示“已选择 N 张”，单张时仍显示文件名。
- 上传期间显示当前序号与总体进度，例如“正在上传 2/5”。
- 上传完成后显示成功和失败数量。
- 单张上传时，用户填写的作品标题继续生效；标题为空时使用图片文件名。
- 多张上传时，每张作品使用各自文件名作为标题，作品说明作为这一批图片的共用说明。
- 上传期间禁用重复提交和重新选择图片。

## 数据流

前端将选中的 `FileList` 转换为 `File[]` 队列，并按选择顺序逐张处理：

1. 尝试上传到 Vercel Blob。
2. Blob 不可用时，沿用现有压缩后的内联图片回退。
3. 调用现有 `POST /api/works` 创建作品记录。
4. 成功记录立即加入本地作品列表。
5. 某张失败时记录失败数量，并继续处理下一张。

本功能不修改数据库结构，也不增加批量 API。

## 错误处理

- 未选择图片时提示先选择图片。
- 某张上传失败不会取消已经成功的图片，也不会阻断后续图片。
- 全部处理结束后清空成功提交的选择队列；若存在失败，提示失败数量，用户可重新选择失败图片再传。
- 本地内联存储被使用时，在完成提示中说明当前处于本地存储模式。

## 验证

- 选择多张图片后，界面正确显示数量。
- 一次提交会为每张图片分别创建作品。
- 多张图片使用各自文件名作为标题。
- 单张图片仍支持手填标题。
- 部分失败时其余图片继续上传。
- 类型检查、生产构建和浏览器交互验证通过。
