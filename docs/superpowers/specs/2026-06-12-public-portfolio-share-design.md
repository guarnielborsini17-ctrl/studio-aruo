# 公开作品链接与图片优化设计

## 目标

让绘图员在工作台生成一个可撤销的专属公开链接，发给设计师查看个人资料、接单状态、作品和收费规则。公开页面不要求登录，不提供工作台或注册入口。新上传的4K效果图在浏览器中生成适合网页展示的版本后再上传。

## 范围

本功能包含：

- 绘图员主动生成随机公开链接。
- 复制链接、关闭分享和重新生成。
- 单页展示绘图员资料、接单状态、作品与价格。
- 公开页面禁止搜索引擎收录。
- 新作品上传前压缩为网页展示图。
- 批量上传显示处理与上传进度。

本功能不包含：

- 4K原图下载或保存。
- 旧图片批量迁移。
- 多个同时有效的分享链接。
- 访问密码、访问统计、留言或在线付款。
- 搜索引擎公开获客。

## 分享数据模型

在 `users` 表增加：

- `share_token TEXT UNIQUE`
- `share_enabled BOOLEAN NOT NULL DEFAULT false`
- `share_updated_at TIMESTAMPTZ`

数据库保存高强度随机令牌，使绘图员换设备或刷新工作台后仍能再次复制同一个链接。令牌是公开链接的访问凭证，不包含账号、手机号或用户 ID。

公开地址使用：

`/#/share/<token>`

令牌使用密码学安全随机值，至少包含 128 位随机性，URL 安全且不可由用户 ID、账号或手机号推算。

## 分享操作

工作台新增“公开作品页”面板：

- 未生成时显示“生成公开链接”。
- 生成后显示完整链接和“复制链接”“关闭分享”“重新生成”。
- 关闭分享只把 `share_enabled` 设为 `false`，当前链接立即返回不可用。
- 重新生成创建新令牌并覆盖旧令牌，旧链接立即失效。
- 页面刷新或换设备后，绘图员仍可在登录工作台查看和复制当前链接。

生成、关闭和重新生成都要求当前登录用户为绘图员，并且只能修改自己的分享状态。

## 分享接口

认证接口：

- `POST /api/share-link`：首次生成或重新生成，返回完整公开 URL。
- `DELETE /api/share-link`：关闭当前分享。
- `GET /api/share-link`：向当前登录绘图员返回当前公开链接、启用状态和更新时间。

公开接口：

`GET /api/public-portfolio?token=<token>`

返回一个只读聚合对象：

- 绘图员展示名、头像、简介。
- `isBusy` 和 `availableDate`。
- 作品列表。
- 套餐价格和价格说明。

接口只在令牌精确匹配且 `share_enabled = true` 时返回数据。无效、已关闭或已被重新生成的令牌统一返回 404，避免泄露账号是否存在。

## 公开单页

公开页面为独立展示布局，依次包含：

1. 头像、展示名和简介。
2. 接单状态与最早排期日期。
3. 作品库。
4. 套餐价格与价格说明。

页面不显示：

- 登录、注册或工作台导航。
- 编辑、上传或保存按钮。
- 用户账号、手机号或内部用户 ID。

页面数据每次打开都从公开接口读取，所以绘图员修改作品、资料、状态或价格后，原链接自动显示最新内容。

页面设置：

```html
<meta name="robots" content="noindex,nofollow,noarchive">
```

React 在进入公开分享路由时动态设置该标签，离开路由时恢复默认值。由于当前应用使用哈希路由，分享路径不会作为独立服务器请求发送给 Vercel，因此不依赖按路径响应头。这能降低被搜索引擎收录的可能，但拿到链接的人仍可转发，因此页面不能被视为严格保密空间。

## 新作品图片处理

现状是上传成功时直接把4K原图发送到 Vercel Blob；只有上传失败的内联备用路径会缩小图片。本功能将上传流程调整为始终先生成展示图。

新作品处理规则：

- 支持 JPEG、PNG 和 WebP 输入。
- 解码时读取图片方向并保持正确朝向。
- 保持原始宽高比，不裁剪。
- 长边超过 2560px 时缩小到 2560px；较小图片不放大。
- 输出 WebP，质量 0.88。
- 删除原文件名中的敏感路径信息，生成新的安全文件名。
- Blob 只保存处理后的展示图。
- 不上传或保存4K原文件。

若浏览器不支持 WebP 编码，则回退到 JPEG 质量 0.88；不能完成解码或压缩时，该图片上传失败并显示明确原因，不再回退上传原图或写入超大的 base64 数据。

## 批量上传体验

每张图片按顺序经历：

1. 正在处理。
2. 正在上传。
3. 正在保存作品。
4. 成功或失败。

工作台显示当前第几张、总张数、处理阶段和进度。单张失败不阻止后续图片；结束后显示成功与失败数量。浏览器一次只处理一张4K图片，避免同时解码多张导致内存占用过高。

## 旧图片

旧图片保持原 URL 和原文件不变。公开页可以同时显示旧原图和新展示图。第一版不进行批量转换，也不删除现有 Blob 文件。

## 错误处理

- 分享生成失败时保留当前状态并提示重试。
- 复制失败时显示链接文本，允许用户手动复制。
- 无效或关闭的分享链接显示“该作品页暂未开放”，不跳转登录页。
- 公开接口部分数据为空时显示对应空状态，不使用全站默认作品或默认价格补齐。
- 图片格式不支持、图片损坏或处理失败时，明确标记失败文件名。

## 测试与验收

自动化测试覆盖：

- 分享令牌生成、唯一性和不可预测性。
- 关闭分享和重新生成后旧令牌失效。
- 公开接口只返回允许展示的字段。
- 公开页面不包含登录、注册和工作台入口。
- 公开页面进入时设置 `noindex`，离开时恢复默认值。
- 4K图片缩小到长边 2560px并保持比例。
- 小图不放大。
- 输出格式和质量参数正确。
- 处理失败时不上传原文件。
- 批量上传一张失败后继续下一张。

人工验收：

1. 绘图员生成链接并复制给未登录浏览器。
2. 未登录设计师可以看到该绘图员的资料、状态、作品和价格。
3. 修改价格或新增作品后，原链接刷新即同步。
4. 关闭分享后旧链接不可访问。
5. 重新生成后旧链接失效、新链接有效。
6. 上传典型4K JPEG/PNG，确认 Blob 中保存的是不超过2560px的展示图。
7. 在桌面和手机视口检查公开页无溢出、无编辑入口。
