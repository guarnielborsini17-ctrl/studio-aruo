# 作品标题编辑功能设计

## 目标

允许绘图员在工作台中自由修改已上传作品的标题。保存后的标题写入数据库，并同步显示在首页作品库和公开分享链接中。

## 范围

- 仅支持修改作品标题。
- 不修改作品图片、说明、上传时间或公开链接。
- 只有作品所属绘图员可以修改标题。
- 标题去除首尾空格后不能为空。

## 工作台交互

每张作品卡片的标题旁增加编辑图标。

1. 点击编辑图标后，标题切换为输入框。
2. 同时显示保存和取消图标按钮，并提供悬停提示。
3. 点击保存后提交新标题；保存期间禁用重复操作。
4. 保存成功后退出编辑状态，并立即更新当前卡片标题。
5. 点击取消后恢复原标题，不发送请求。
6. 空标题不允许提交，并在工作台显示明确提示。
7. 请求失败时保留编辑内容，允许用户重试。

每次只编辑一张作品，避免多个未保存标题同时存在。

## API 与权限

扩展现有作品详情接口：

- `PUT /api/works/:id`
- 请求体：`{ "title": "新的作品标题" }`
- 成功响应：`{ "work": Work }`

服务端处理：

1. 验证登录状态。
2. 清理并验证标题。
3. 使用作品 ID 和当前用户 ID 更新记录。
4. 非作品所有者或作品不存在时返回 `404`。
5. 返回更新后的完整作品数据。

统一 API 路由增加 `PUT works/:id` 映射，继续保持单个 Vercel Function。

## 数据同步

无需新增数据库字段。现有 `works.title` 是唯一标题来源：

- 工作台保存后更新本地作品列表。
- 首页作品库重新请求作品时显示新标题。
- 公开分享页重新请求公开作品数据时显示新标题。
- 已生成的分享链接不变，也不需要重新生成。

## 测试与验证

- API 测试：作品所有者可以修改标题。
- API 测试：空标题被拒绝。
- API 测试：不能修改其他用户的作品。
- 路由测试：`PUT /api/works/:id` 可到达统一 API 函数。
- 前端验证：编辑、取消、保存中和失败状态正确。
- 集成验证：保存后刷新工作台、首页作品库和公开分享页，三处标题一致。
